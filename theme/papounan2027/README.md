# Papounan 2027 theme

Standalone minimal classic theme for chateaupapounan.fr (no parent theme).

- No design. Layout comes from CrocoBuilder Theme Builder templates; styling from CrocoBuilder and `papounan-design-system.css` (site plugin).
- The only change from CrocoBuilder Blank 1.0.0: content is wrapped in `<div id="primary">` instead of `<main>`, so CrocoBuilder body templates provide the page's single `<main>` landmark. The skip link targets `#primary`.
- Site features (shortcodes, tokens, ex child-theme functions) live in the site plugin, never here.
- `Update URI: false`: never updated from wordpress.org.

Derived from [CrocoBuilder Blank](https://github.com/MjHead/crocobuilder-blank) 1.0.0 by Crocoblock. License: GPLv2 or later.
